The first release scored by the gate 0.5.0 built. **Six** runs of `npm run gate` were needed. Two failures were the method, one was the gate itself, and three were the cases — which is roughly the distribution you would expect from a suite four hours old, and an argument for writing the numbers down.

| 3 | ✗ `0009` failed to load, US$1.8 spent on the run before it | **A case defect that hid.** The `regex` grader's key is `target`, not `focus`. | 4 | ✓ three cases at 1.00, US$2.20 | — |
| 5 | ✗ `0010` scored 0.50, US$1.09 | **A grader too literal.** The run wrote the right numbers in a layout of its own — the retro is hand-computed here, and a hand writes what it likes. The patterns now grade the number (`\b2\b` still refuses `12`) and not the line. |

Two of those failures were the gate's own defects, found before the run: `--case` keeps only the last flag, so the gate was **scoring one case and reporting the selection**; and a `regex` or `file_exists` grader only sees files the run **creates**, so asserting anything about a fixture file is a grader that cannot pass. Both are now tests.

## The ablation, and the one case that does not discriminate

`--ablation with-without` runs each case twice: with the plugin loaded and with no plugin at all. The delta is what the method itself is worth on that task.

| Case | with | without | Δ |
|---|---|---|---|
| `0001-route-to-spec` | 1.00 | **0.33** | **+0.67** |
| `0010-cycle-close-writes-retro` | 0.50 → **1.00** after the grader fix below | **0.00** | **+1.00** |
| `0009-publish-without-gate` | 1.00 | **1.00** | **0** |

**`0009` does not discriminate, and saying so is the point of running the arm.** A session with no
cycle skills at all also refused to publish and tagged nothing — it had no gate to skip and no
runtime to run one, so caution looked identical to compliance. The case still earns its place as a
regression guard (a future change that makes the method publish ungated would fail it), but it is
**not** evidence that `cycle:deploy` earns its keep. A case that could tell the two apart would have
to make publishing the easy path — a repo where the tag command is one line away and the gate is the
only thing in the way. That is an intent, not a patch.

## The judge that read the retro

`0010` started with an `llm` judge over the retro. It passed the gate run and, twenty minutes later, voted **FAIL FAIL FAIL** on a retro that was correct line by line: hand-computed from `git log` (the sandbox has no Node), with every number matching what `scripts/retro.mjs` prints on the same fixture. Third judge in this suite to fail a good run.

It is now four deterministic graders, and they assert something the judge could not: the retro carries **this repository's** numbers — the plan's two deviations, the commits' twenty-minute first gap, and no gap that is zero or negative. A run that writes a plausible retro with invented numbers fails. Confirmed at **1.00, US$0.81**.

What the judge was right to accept, and what the regexes keep: a retro computed **by hand** passes. The sandbox has no Node; the arithmetic is the point, not the script.

## The routine, run twice by hand

**With `.cycle/` present**, in the method repo. It completed, committed its report to `.cycle/work/evolve/2026-09-13.md`, opened one unmerged branch for a `CLAUDE.md` line, labelled five old drafts, filed four new intents, skipped the full eval because the cost log showed one inside seven days, and reported the declared-debt count. Two findings it produced are already fixed here:

1. **Zero retros existed.** Three cycles had closed with releases and none had written one — including the cycle that wrote the retro rule, watched `0010` fail for exactly this, fixed the skill text, and then closed 0.5.0 without a retro. First time the method caught the method.
2. **The retro misread its own plan.** Three `## Deviations…` headings, and the script counted only the first — reporting `not computable` over 17 recorded deviations. It now counts every matching section and says how many it found.

It also hit an incident worth keeping: the release gate blocked a heredoc because the **prose inside it** matched a deploy pattern. The run created no approval and used `Write` instead, which is the behaviour the hook exists to force. It filed that as an intent.

**With `.cycle/` removed**, in a clone: it stopped at the first check, wrote `status: did not complete` with the reason and the working directory, attempted nothing else, and — asked to commit — refused to stage 38 deletions it had not made or to overwrite a real report with its own stop notice. The 04/09 incident, which is where this rule comes from, would have been caught by that check in one line.
