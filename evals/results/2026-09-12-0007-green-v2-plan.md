# Discount at checkout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use cycle:subagent-driven-development (recommended) or cycle:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `charge()` accepts a coupon code, resolves it on the server, applies the percentage discount in integer cents (rounded once, in the customer's favor), never charges zero, and returns the audit fields finance needs.

**Architecture:** `resolveCoupon(code)` in a new `src/coupons.js` holds the server-side coupon registry (SET10 = 10% through 23:59:59 of 2026-09-30 in America/Sao_Paulo), reads the clock from a module-level `clock` object (the only test hook), and throws a `CouponError` with a `code` of `malformed`, `unknown` or `expired`. `charge(customerId, amountCents, { coupon })` in `src/billing.js` calls it, computes the discount in integer arithmetic, logs one JSON line per coupon outcome, and returns `{ customerId, originalAmountCents, discountCents, coupon, amountCents, status }`. No new dependency. No checkout UI (spec: out of scope).

**Tech Stack:** Node ESM, `node tests/run.js` (the repo's only test runner, no framework).

**Decisions the gates forced (each one is a line in Risks):**
- Expiry boundary is São Paulo time, not UTC: `2026-10-01T02:59:59.999Z`. **Ana confirms this at acceptance**; if the campaign said UTC, change one string and one test.
- A blank or whitespace coupon means "no coupon" and charges full price. Only a non-string coupon, an unknown code or an expired code rejects the charge.
- The clock lives in `coupons.js`, not on the `charge()` signature. An invalid clock throws instead of disabling expiry.
- `charge()` takes an options object as the third argument. A string in that position throws `invalid options`, so an old-style caller fails loudly instead of being silently mis-parsed.
- Errors carry a `code` so support and logs can tell expired from mistyped. The messages do not say which codes exist.
- R5 "a favor do cliente" is implemented as round-up of the discount (1001 → 101). The finance council confirms this reading at acceptance; the market default is half-up.
- `amountCents` is applied as received; whether it is pre-tax or post-tax is the caller's contract. Research left tax unchecked; this plan does not resolve it.
- The audit record is the return value. Persisting it for finance belongs to the caller; the deploy checklist confirms the caller stores `originalAmountCents`, `discountCents` and `coupon`.
- The next campaign's coupon is one entry in the registry plus a deploy. No config or admin path in this slice; the written answer to "does the next campaign need a code change" is yes.
- The expired SET10 entry stays in the registry after 30/09 so the customer keeps getting `expired` instead of `unknown`. No removal task.

**Spec drift removed from the previous draft:** the customer-facing sentence, its text file and the three-field return shape are gone. The spec's R3 fixes the return fields and puts the checkout UI out of scope. The draft had also dropped `customerId` from `charge()`; the existing signature is kept.

// Coupons: the only place a percentage comes from. The client sends a code, never a number.
// The registry is code, not config: the next campaign's coupon is one entry here plus a deploy.
// Expired entries stay so the customer gets "expired", not "unknown".

// The only clock in the module. Tests replace clock.now; production never does.
export const clock = { now: () => new Date() };

const COUPONS = {
  // expiresAt is inclusive and is 23:59:59 on 2026-09-30 in America/Sao_Paulo (UTC-3),
  // which is 02:59:59 UTC on 2026-10-01. Confirmed by Ana at plan acceptance.
  SET10: { percent: 10, expiresAt: '2026-10-01T02:59:59.999Z' },
};

export class CouponError extends Error {
  constructor(code, message) { super(message); this.name = 'CouponError'; this.code = code; }
}

export function resolveCoupon(code) {
  if (typeof code !== 'string' || code.trim() === '') throw new CouponError('malformed', 'coupon malformed');
  const key = code.trim().toUpperCase();
  const c = COUPONS[key];
  if (!c) throw new CouponError('unknown', 'coupon unknown');
  const now = clock.now();
  if (!(now instanceof Date) || !Number.isFinite(now.getTime())) throw new Error('invalid clock');
  if (now.getTime() > Date.parse(c.expiresAt)) throw new CouponError('expired', 'coupon expired');
  return { code: key, percent: c.percent };
}
```

// Billing: charges the customer card. Money moves here.
import { resolveCoupon, CouponError } from './coupons.js';

// charge(customerId, amountCents, { coupon }) — coupon is a code string or absent; never a percent.
export function charge(customerId, amountCents, options = {}) {
  if (options === null || typeof options !== 'object' || Array.isArray(options)) throw new Error('invalid options');
  if (!Number.isInteger(amountCents) || amountCents <= 0) throw new Error('invalid amount');

  const raw = options.coupon ?? null;
  if (raw !== null && typeof raw !== 'string') throw new CouponError('malformed', 'coupon malformed');
  const requested = raw === null ? '' : raw.trim();

  let discountCents = 0;
  let coupon = null;
  if (requested !== '') {
    let resolved;
    try {
      resolved = resolveCoupon(requested);
    } catch (err) {
      console.log(JSON.stringify({ event: 'coupon', outcome: err.code ?? 'error', customerId }));
      throw err;
    }
    coupon = resolved.code;
    // R5: round once, integer cents, in the customer's favor (discount rounds up). Integer arithmetic only.
    const num = amountCents * resolved.percent;
    discountCents = Math.floor(num / 100) + (num % 100 ? 1 : 0);
  }

  const finalCents = amountCents - discountCents;
  if (finalCents <= 0) {
    console.log(JSON.stringify({ event: 'coupon', outcome: 'zeroed', customerId, coupon }));
    throw new Error('amount zeroed by coupon'); // R4: never charge zero or negative
  }
  if (coupon) console.log(JSON.stringify({ event: 'coupon', outcome: 'applied', customerId, coupon, discountCents }));

  return {
    customerId,
    originalAmountCents: amountCents,
    discountCents,
    coupon,
    amountCents: finalCents,
    status: 'charged',
  };
}
```
